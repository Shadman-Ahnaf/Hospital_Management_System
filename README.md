# Hospital Management System

A web-based Hospital Management System developed using ASP.NET Core MVC and Entity Framework Core. The system provides role-based access and management features for administrators, doctors, receptionists, and patients.

## Features

- Role-based authentication and authorization
- Patient management
- Doctor and receptionist management
- Appointment scheduling and management
- Medical records and prescriptions
- Department management
- Patient profile management
- Password management
- Administrator reports and system monitoring
- SQL Server database with Entity Framework Core migrations

## User Roles

- **Administrator** – Manage users, doctors, receptionists, departments, and reports
- **Doctor** – Manage appointments, patient records, diagnoses, and prescriptions
- **Receptionist** – Register patients and manage appointments and patient information
- **Patient** – Book appointments and view appointments, medical records, prescriptions, and profile

## Technology Stack

- C#
- ASP.NET Core MVC
- .NET 10
- Entity Framework Core
- SQL Server
- ASP.NET Core Identity
- Bootstrap
- HTML/CSS/JavaScript

## Architecture

The project follows the **Model-View-Controller (MVC)** architecture with Entity Framework Core for database operations and ASP.NET Core Identity for authentication and role-based authorization.

## Database

The application uses **Microsoft SQL Server** and Entity Framework Core Code First migrations.
